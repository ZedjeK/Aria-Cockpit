== Runtime .NET (version autonome seulement) ==

La version autonome embarque le runtime .NET 10 dans chaque exe ; la version
légère s'appuie sur le runtime installé sur la machine et ne le redistribue pas.

Composant                      Version   Licence  Projet
Microsoft.NETCore.App          10.0.x    MIT      https://github.com/dotnet/runtime
Microsoft.WindowsDesktop.App   10.0.x    MIT      https://github.com/dotnet/wpf
  (WPF, dans Aria-Cockpit.exe seulement)

10.0.x : la version du SDK .NET 10 qui a compilé la release.
Le runtime intègre lui-même des composants tiers, sous leurs propres licences :
  https://github.com/dotnet/runtime/blob/main/THIRD-PARTY-NOTICES.TXT
  https://github.com/dotnet/wpf/blob/main/THIRD-PARTY-NOTICES.TXT
(Les paquets System.* ci-dessus renvoient aux mêmes mentions.)
